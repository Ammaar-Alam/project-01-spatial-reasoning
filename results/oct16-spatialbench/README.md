# SpatialBench comparison

Imported existing results: 24 tasks, seven model configurations, 160 graded responses and eight unreturned outcomes. `run.json`, `records.jsonl` and the run's task snapshots use the repository's normal layout. The native Results viewer opens this run without extra tools.

The original replies, model settings, task fingerprints, code identifier and execution commit are preserved. Task JSON files use the editor's Biome formatting; their parsed fields, image bytes and model requests are unchanged. This assembled comparison is historical data, not a new execution by the current checkout.

Some task inputs are custom count maps, piece layers and camera/corridor diagrams. These are deliberately authored clues, not exports of the harness's 3D snapshot renderer. See [task notes](../../docs/spatialbench.md).
