# Spatial Reasoning Benchmark

A COS 597C Project 1 benchmark by Ammaar Alam and Erik Dyer for evaluating spatial reasoning through one-shot construction and manipulation tasks.

Tasks provide a starting structure or images, a goal, and any applicable constraints. Models return a complete structure as JSON or identify an impossible or underspecified task. A shared harness evaluates each response against task-specific correctness rules.

The planned suite includes spatial transformations, image reconstruction and viewpoint tasks, and constrained editing puzzles. Results will include task-level pass/fail scores and visual comparisons of expected and generated constructions.

The repository is initialized. Implementation, the task collection, and measured results are forthcoming.
